# Каталог продукции «Вектор-Сервис»

## Инструкция запуска
Рекомендуемый способ — локальный сервер: Windows — двойной клик по `start.bat`; macOS и Linux — `./start.sh`; вручную — `python -m http.server 8000`, затем http://localhost:8000. Каталог можно открыть и двойным кликом по `index.html` — тогда используется встроенная копия данных (`data/catalog.embedded.js`), так как браузеры блокируют `fetch` для файлов с диска. 

## Источник тестовых данных
Предприятие, бренды («Вектор», «Нова», «Ферум», «Квант», «Орбита»), товары, цены, остатки, рейтинги и характеристики вымышлены и сгенерированы ИИ-ассистентом Claude (Anthropic). Файл `data/catalog.json` собирает скрипт `tools/make_catalog.py`, он же обновляет встроенную копию. Запрос к ИИ (суть): *«Создай каталог на 30+ позиций вымышленного поставщика запчастей и инструментов для ремонта электроники: 6 категорий, вымышленные бренды, цены в рублях, наличие (часть товаров отсутствует), рейтинг, гарантия, 5 характеристик и краткое описание у каждого товара»*. Состав: 36 товаров, по 6 в каждой категории (дисплеи и стёкла, аккумуляторы, разъёмы и шлейфы, микросхемы и компоненты, инструменты и оборудование, расходные материалы); цены от 45 до 18 500 ₽, рейтинг от 4,0 до 4,9, у 5 товаров нет остатка, у части есть метки «Хит» и «Новинка».

**Обоснование:** реальные цены и модели не нужны — кейс проверяет интерфейс. Разброс цен, наличия, брендов и категорий подобран так, чтобы проверить поиск, комбинации фильтров, сортировку, пустой результат и карточку товара без наличия.

**Этическая и юридическая оговорка:** данные не содержат персональных данных. Бренды и названия вымышлены, товары описаны обобщённо, без привязки к торговым маркам реальных производителей. Фотографий нет — иконки категорий нарисованы вручную как SVG. Телефон условный. Тексты лицензий шрифтов лежат в `fonts/`.

## Архитектура обмена данными
Клиент работает с данными через слой `js/api.js`, который имитирует REST: `GET data/catalog.json` — справочник категорий и список товаров. Порядок работы: страница показывает скелетон и запрашивает каталог через `Api.getCatalog()`; ответ проверяется (структура и типы) и сохраняется в памяти без повторных запросов; состояние фильтров берётся из адресной строки, затем строятся панель фильтров и список; фильтры и сортировка применяются к данным в памяти без новых запросов; после каждого изменения адрес обновляется; при ошибке сети, таймауте (8 секунд) или неверном формате показывается сообщение с кнопкой «Повторить»; при открытии из `file://` слой данных берёт встроенную копию. Параметры адреса: `q` (до 60 символов), `cat`, `brand` (через запятую), `min`/`max` (целые), `stock=1`, `sort` (`price-asc`, `price-desc`, `name`, `rating`).

## Состояния интерфейса (для проверки)
| Состояние | Как показать |
|---|---|
| Загрузка | Открыть `index.html?demo=slow`: скелетон 2,5 секунды |
| Ошибка загрузки | Открыть `index.html?demo=error`: сообщение и кнопка «Повторить» |
| Пустой результат | В поиске ввести «абвгд» |
| Нет такого товара | Открыть `product.html?id=999` |
| Товар не в наличии | Открыть `product.html?id=4` |
